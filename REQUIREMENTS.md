# REQUIREMENTS

## Hardware Requirements
- Minimum: 8 GB RAM
- Recommended: 16 GB RAM for smooth Docker execution
- Storage: At least 5 GB free disk space for Docker image and artifacts

## Software Requirements
- Operating System: Linux, macOS, or Windows (with Docker support)
- Docker: Required (tested with Docker 20.x and above)

## Python Environment
- Python 3.10+ (if running outside Docker)

## Dependencies
All required dependencies are pre-installed in the Docker image.

If running natively, install dependencies via:
pip install -r requirements.txt
